# RouteNex - Phase 6 (demo and viva package + two safety tools)

Copy into your project folder (nothing existing is overwritten except `docs/` additions):
- `docs/RouteNex_Demo_and_Viva_Package.pdf` (and an editable `.md` copy)
- `preflight.bat` + `tools/preflight.py`  - run while the app is running; says READY or what to fix
- `reset_demo.bat` + `database/reset_demo.py` - clean, repeatable demo data (recreates your admin login)

Use: start.bat -> preflight.bat -> practise the 10-minute script. Before the real demo: reset_demo.bat, start.bat, preflight.bat.
